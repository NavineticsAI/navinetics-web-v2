01 — Foundations

Tokens, not hex codes.

Every colour, size and duration is a named variable with a light and dark value. Components read the semantic name; the theme decides what it resolves to. This is what makes a real toggle possible.

02 — Material

Liquid glass, done properly.

Most "glassmorphism" is a blur and a white border — and a blur alone is not glass, because glass bends light. Building the refraction properly surfaced a constraint worth designing around: heavy frosting and visible refraction cannot coexist, because blur destroys exactly the high-frequency detail that makes bending legible. So this is two materials, not one.

Frosted. Heavy blur, 60% tint, no displacement. Tuned so text sitting on the glass stays crisp — navigation, toolbars, modals, anything you read off. Three blur tiers below.
Lens. 5px blur, 26% tint, hard edge refraction. Tuned so the world behind the glass distorts — hero panels, product callouts, showcase moments. The lab below.
FROSTED · CHROME

14px blur

Navigation bars, pills, toolbars. Thin enough to keep text behind it legible as you scroll.

FROSTED · SURFACE

26px blur

Cards floating over imagery, spec callouts, the pinned captions on a product scroll sequence.

FROSTED · MODAL

40px blur

Dialogs, mega-menu panels, image lightboxes. Heavy enough to fully separate foreground from page.

Both are real canvases from this page, drawn from a rounded-rectangle signed-distance field. Because the map is built from the element's own width, height and border-radius, the bevel follows the corner curve exactly instead of approximating it.

Why not turbulence

The widely-copied glass trick feeds feTurbulence into the displacement map. That warps the whole panel evenly, which reads as rippled or frosted glass — a bathroom window. Real optical glass barely refracts through the middle, where the surface is flat, and refracts hard at the edge, where it curves. Building the map from the shape's own distance field is what produces that falloff.

Set Bevel width low and Edge refraction high to see the effect concentrate into a bright rim; widen the bevel and it becomes a soft dome.

Then drag Blur up and watch the refraction disappear. Measured on this page against an identical refraction-off render, the share of pixels that actually change falls off a cliff:

Which is why the default sits at 5px and why frosted chrome doesn't refract at all. Reordering the filter so blur runs first is worse, not better — it takes the effect to zero, because there is no detail left to bend.

The seven layers

backdrop-filter: blur(26px) saturate(1.9) — the saturation boost is the part people skip. Without it, blurred content behind glass goes grey and the panel reads as frosted plastic.

A 1px gradient border — bright at the top-left, near-invisible through the middle, bright again bottom-right. Drawn with mask-composite: exclude so it's a true ring, not a background bleed. This single detail separates real glass from a flat stroke.

An inset highlight on the top edge and an inset shadow on the bottom. The eye reads the pair as a physical slab with depth rather than a decal sitting on the page.

A radial highlight positioned from two CSS variables the pointer writes. Glass that never changes as you move past it reads as a picture of glass. This is the "liquid" part — and it costs one mousemove listener.

A tight 1–2px contact shadow anchoring it to the surface, plus a wide soft ambient shadow. One blur alone always looks like a sticker.

The backdrop is physically displaced through an feDisplacementMap whose map is generated from the panel's own rounded-rectangle distance field. Because backdrop-filter operates on whatever is actually behind the element, this bends real page content — text, images, other panels — not a decorative overlay. A second radial lens is summed onto that map and repositioned from the pointer, so the distortion tracks the cursor.

Glass disperses wavelengths at slightly different angles. Running the displacement three times at marginally different scales and recombining one channel from each produces the faint colour fringing you see at a real lens edge. It is the detail that reads as expensive — and the first one to drop if a device struggles.

L6 and L7 are Chromium-only. Safari and Firefox support backdrop-filter but not SVG filter references inside it. They get L1–L5 plus a masked ring that re-blurs the backdrop at the bevel — convincing thickness, just not true displacement. The refraction layer is added by script only after the capability is confirmed, so an unsupported browser never loses its blur.
Implementation — the refraction pass 
// 1. bevel map from the panel's own rounded-rect SDF
for (each pixel) {
  // signed distance: negative inside
  qx = abs(px) - hw + r;  qy = abs(py) - hh + r;
  sd = hypot(max(qx,0), max(qy,0))
     + min(max(qx,qy), 0) - r;

  if (sd < 0 && sd > -bevel) {
    t = -sd / bevel;          // 0 at edge, 1 inside
    k = (1 - t) ** 2;         // convex falloff
    n = normalize(edge gradient);
  }
  // 128 is neutral; R drives X, G drives Y
  R = 128 + n.x * k * 127;
  G = 128 + n.y * k * 127;
}

<!-- 2. sum bevel + pointer lens, displace once -->

            result="neutral"/>
  <feImage  href="{lensPNG}" result="blob"/>
  <feComposite in="blob" in2="neutral"
               operator="over" result="full"/>
  <!-- k2 fades the pointer lens in/out -->
  <feComposite in="full" in2="neutral"
     operator="arithmetic" k2="a" k3="1-a"
     result="ptr"/>
  <feImage  href="{bevelPNG}" result="edge"/>
  <!-- both centred on 0.5, so subtract one -->
  <feComposite in="ptr" in2="edge"
     operator="arithmetic" k2="1" k3="1"
     k4="-0.5" result="map"/>

color-interpolation-filters="sRGB" is not optional — the default is linearRGB, which shifts where "neutral" sits and smears the whole panel sideways.

Where glass is banned. Never behind long-form reading (Education, Publications, founder bios) — translucency under body copy is a legibility and accessibility problem, not a style choice. Glass belongs on chrome, on things floating over imagery, and on modals. Roughly: if you'd read it for more than ten seconds, it sits on a solid surface.
Refraction has a budget. Each refracting panel is a full backdrop re-filter every frame it changes, so the rule is at most three on screen at once — and never on the sticky navbar, which would re-filter on every scroll pixel. Nav and buttons keep L1–L5. Refraction is for hero glass, product callouts and modals: the moments that are meant to feel expensive.
03 — Signature motif

The reticle system.

Your CT and X-ray localisers already draw crosshairs and graduated scales. That's the ornament language — borrowed from the instrument itself rather than invented. Corner marks frame anything being targeted: a product shot, a key figure, a featured spec. Used sparingly, it's unmistakably yours.

Framed subject

Corner marks only — the frame implies a target without boxing the content in.

Graduated edge

A measurement rule along one edge. Section dividers, table headers, the top of a spec panel.

Iso-center mark

Concentric arcs converging on a point. Watermark for hero and section backgrounds.

Restraint rule. One reticle device per viewport, maximum. The moment corner marks appear on every card they stop meaning "this is the target" and become wallpaper — which is exactly how a distinctive motif turns generic.

08 — Disclosure

Depth without a wall of text.

Education runs to 400-word blocks of dense electrochemistry. Tabs and accordions let a surgeon skim and a researcher drill in, from the same page.

Arc-centred targeting

Three linear degrees of freedom place the target at the focus of the arc, while two angular rotations about that focus set the trajectory. Fixation to the skull establishes a three-dimensional coordinate system, linking imaging data to patient anatomy.

Measuring the living brain

Dopamine, serotonin and norepinephrine are instrumental in normal brain function. WINCS enables both preclinical research and human recordings, addressing a critical gap in understanding normal and pathologic neurophysiology.

Fast-scan cyclic voltammetry

The electrode potential is scanned linearly, oxidising or reducing adjacent molecules; the measured current carries chemical information about the surrounding environment. Scan rate and potential limits determine sensitivity, selectivity and time resolution.

Accordion — technical detail on demand

Rotational elements provide two angular degrees of freedom — one about the X axis (ring or collar angle), one about the Y axis (arc angle). Both pivot about a single point.

The X and Y axes pivot about a single point — the iso-center, or focus — which is the stereotactic target. Two degrees of freedom let that point be approached from many directions.

Holds and guides electrodes, leads and surgical instruments along a trajectory projecting through the iso-center, letting surgeons optimise the path used to reach a target.

10 — Motion

Cinematic, but disciplined.

You picked a cinematic direction, so motion carries real weight — but four curves and five durations, not per-component guesswork. Click any track to replay.

Non-negotiables

Not one animation in the current codebase checks prefers-reduced-motion. For a site whose audience includes people with movement and vestibular disorders — Parkinson's, essential tremor, dystonia — that is the wrong default. Scroll-pinned sequences degrade to plain stacked sections; nothing is lost but the movement.

The 300vh pinned sequence on Frame System is the best moment on the site and worth keeping. It gets a capped length, keyboard navigation between steps, and a visible progress indicator so nobody feels trapped.

Animating width, height, top or left forces layout on every frame. Backdrop-filter is expensive too, so glass panels animate opacity and transform — never their blur radius.

Fixes that ride along

index.html sets bg-black text-white on body while App forces white — every cold load flashes black. The theme script resolves this before first paint.

tailwind.config.js is v3-format and silently ignored under Tailwind v4, which reads @theme from CSS. It gets deleted so nobody edits it expecting an effect.

Body copy set in text-gray-400 on white lands near 2.8:1 — below the 4.5:1 minimum. Publications and Frame System both do this. Tokens fix it everywhere at once.

It's on every product image, and it only works over white — on the dark theme those shots turn to black mush. They need real transparent-background cutouts. Until you can supply them I'll wrap each image in a light "product plate" that stays light in both themes, so nothing breaks in the meantime.

The Community page pulls its cityscape straight from Unsplash's CDN — an uncontrolled external dependency on a page you own. It should be a local asset with a licence you can point to.

The tab still shows the Vite logo despite /favicon.svg sitting in public. No route sets its own title or description either, so every page shares one generic tag.

Sequencing. Tokens and the component library first, then pages migrate one at a time — so the site keeps working at every step and you can review each page as it lands.
