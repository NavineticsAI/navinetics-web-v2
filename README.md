# NaviNetics Web v2

This is the next-generation website for NaviNetics, built with React, Vite, and Tailwind CSS.

## Features
- **Modern UI/UX**: Premium animations with Framer Motion.
- **Fast Build Times**: Powered by Vite.
- **Responsive**: Mobile-first Tailwind styling.

## Scripts
- `npm run dev`: Start development server
- `npm run build`: Build for production
- `npm run preview`: Preview production build
